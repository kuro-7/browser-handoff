# セキュリティの報告

browser-handoff は α 版です。引換券の漏れや、他人のアカウントを受け取れてしまう道など、セキュリティに関わる問題を見つけたら、公開の Issue ではなく、GitHub の **Security** タブの「Report a vulnerability」から知らせてください（報告は作者にだけ見えます）。

それ以外の質問や不具合は、Issues へどうぞ。

## Reporting a vulnerability

Please do not open a public issue for security problems (for example, a way to leak a ticket or to take over someone else's account). Use **Security → Report a vulnerability** on GitHub instead; the report is visible only to the maintainer.
